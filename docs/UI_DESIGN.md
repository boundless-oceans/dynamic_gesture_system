## 一、首页

- 大标题"庐州非遗"：宽 1/4 页面宽，高 1/8 页面高
- 右上角：摄像头实时画面（始终存在），宽 1/6 页面，高 1/8 页面
- 中间按钮（整体居中）：葫芦烙画、刘铭传故事、包公故事、庐剧、火笔画、吴山铁字
  - 每个按钮：宽 1/8 页面宽，高 1/3 页面高
  - 按钮之间有空隙
  - 按钮下方居中显示模块名（标题宽度约按钮宽度的 1/2）
  - 按钮中上部为对应图片
  - 选中按钮变大 + 边框变橙色
  - 左右箭头切换按钮组
- 下方：关闭摄像头按钮（文字约为标题的 2/3），始终存在
- 背景：白色到蓝色渐变

## 二、详情页

- 【已过时】~~3D 模型居中：宽 1/5 页面宽，高 3/4 页面高~~
  → 现为**左侧作品图自动轮播（3.5s，带页码点）+ 右侧项目信息卡**
  （类别 / 传承人 / 详实简介），信息卡整体下移避开右上角摄像头悬浮窗
- 底部按钮：返回主页、非遗详情、交互展示
- 手势可切换选中按钮，再用手势进入对应界面

### 非遗详情

- 左上角标题"庐州非遗"
- 左侧介绍区：宽 1/6 页面，高 2/3 页面
  - 历史渊源（加粗标题）
  - 技艺特点（加粗标题）
  - 传承现状（加粗标题）
- 右侧视频区：宽约 3/5 页面，高与介绍区相同
- 视频右侧：3 张图片纵向排列

### 交互展示

- 全屏 3D 模型
- 手势控制：放大、缩小、旋转
- 右下角圆形返回按钮

## 三、通用

- 摄像头开启时画面始终在右上角
- 关闭摄像头按钮始终在页面下方
- 背景色：白色到蓝色渐变
